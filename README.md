
# Hospital Management System

## Project Overview
A web-based Hospital Management System built as a personal learning and portfolio project.

## Planned Modules
- Doctor Management
- Patient Registration
- Room Management
- Patient Admission
- Doctor Assignment
- Room Allocation and Shifting
- Billing and Payments
- Patient Discharge
- Reports

## Technology Stack
- C#
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- Angular
- Git and GitHub

## Architecture
ASP.NET Core Web API with Entity Framework Core using the Code First approach.

Day 1: Development environment setup and project structure creation.
